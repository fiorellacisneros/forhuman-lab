# forHuman Lab

Laboratorio de experimentos de forHuman. Este repo aloja el sitio donde probamos ideas, herramientas y productos antes (o en lugar) de llevarlos a producto formal.

## Proyectos

- **[flowmcp](https://github.com/fiorellacisneros/flowmcp)** — CLI open source que conecta Webflow a agentes de IA (Claude Code, Claude Desktop, Cursor, ChatGPT, Codex) sin exponer tokens al contexto del agente.

La idea es que la mayoría de lo que construyamos aquí termine siendo open source. Si algo te sirve, úsalo, rómpelo, mándanos un PR.

## Sobre este sitio

Construido con Next.js + Tailwind. Es una simulación de escritorio (macOS/iPhone) donde cada "app" del dock es un experimento o proyecto distinto.
